📊 Set Up Google Sheets

Your data lives in your own Google Sheet — free and private.

  1. Click here to create a new Google Sheet
  2. Name it (e.g. "My Store Sales") and go to Extensions → Apps Script
  3. Delete any code and paste the entire content from the gas/Code.gs file
  4. Click Save → Deploy → New Deployment → Web App
  5. Set "Execute as: Me" and "Who has access: Anyone"
  6. Click Deploy and copy the Web App URL
  7. In the Apps Script editor, run the function createTemplateSheets
  8. Run the function setApiToken() and copy the printed token (BARCODEPOS_TOKEN)

✅ All Set!

You're ready to start scanning products and making sales.

    ❓ Help & FAQ

    🔧 Setup

    • Create the Google Sheet: open sheets.new, name it, then go to Extensions → Apps Script.
    • Deploy the Apps Script: paste the entire contents of the gas/Code.gs file, click Save → Deploy → New Deployment → Web App, set "Execute as: Me" and "Who has access: Anyone", then copy the Web App URL.
    • Set the API token: run setApiToken() in the Apps Script editor and copy the printed token.
    • Connect: paste both the Web App URL and token into Settings → Google Sheets and press Test Connection.

    👥 Roles

    • Manager: full access — checkout, products, sales, team, stores, stock, settings, alerts.
    • Stock Manager: adds products and manages stock (receive, transfer, return) at the warehouse or a shop.
    • Cashier: checkout and their own sales history only. Cannot edit prices or stock.

    🛒 Scanning & Checkout

    • Scan or type a barcode to add an item. Not found? You can quick-add it (Stock Manager), or ask a stock manager to add it.
    • Adjust quantities with the − / + steppers before completing the sale.
    • Void a sale with "✕ Cancel Sale" — it is recorded as voided, never deleted.
    • Receipts: share or print from the receipt modal, or reopen the last one with "🧾 Last Receipt".

    📦 Stock

    • Receive new goods, transfer between warehouse and shops, and return defective stock — all from Stock Management.
    • Archive a product to hide it from lists and sales without deleting it.
    • Stock alerts highlight out-of-stock and low-stock items so you can restock in time.

    📡 Sync & Offline

    • Everything you do works offline — sales, products and stock are stored on this device first.
    • Changes are queued and sync automatically to Google Sheets when you're back online (retried on a schedule).
    • Use 🔄 Sync Now or Settings → Test Connection to force a sync or check connectivity.

    🛠️ Troubleshooting

    • "Invalid token": re-run setApiToken() and paste the new token in Settings.
    • Not syncing: check the Web App URL, redeploy the script as a new version, and make sure access is set to "Anyone".
    • Camera not working: allow camera permission in the browser, or use "✏️ Type Barcode".
    • Seen an old screen after an update? The PWA caches files — do a hard refresh (pull-to-refresh, or clear site data) to get the latest build.
